# VisionQA

AI-powered visual regression testing assistant.

## Features

- Compare Expected Design vs Actual Screenshot
- Detect visual UI differences
- Highlight changed areas
- Generate QA analysis
- Interactive chatbot interface

## Tech Stack

- Python
- Streamlit
- OpenCV
- SSIM
- NumPy
